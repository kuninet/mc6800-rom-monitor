# VDG + keyboard SDFS/68 実機確認手順

## 目的

VDG画面と2nd ACIAキーボードだけで、ROMモニタからSDFS/68を起動し、基本操作できることを確認する。
UARTはデバッグ用の逃げ道として残す。

この手順は #170 の実機確認用である。
次のPRが取り込まれた後に確認する。

- #197: SDFS/68実行時のVDG余分改行抑止。
- #198: VDG有効時の1st ACIA送信待ち停止回避。
- #199: VDG向け短幅ダンプ `DS`。

## 前提

- ROM profile は `sbcio_vdg` または `k6802_vdg` を使う。
- `FEATURE_VDG=1`、`FEATURE_KEYBOARD=1`、`FEATURE_SD=1`、`FEATURE_FAT=0` の構成である。
- K68-VDG の制御レジスタは `$8110`。
- 2nd ACIAキーボードは `$8094-$8095` に接続する。
- system SD には stage1 と `SDFS.BIN` を配置する。
- UARTを接続する場合も、通常操作はキーボードから行う。

## ROM起動確認

1. VDG、2nd ACIAキーボード、system SD を接続して電源を入れる。
2. VDG画面に `MC6800 MONITOR` と `]` プロンプトが表示されることを確認する。
3. 1st ACIA UARTを外した状態でも、起動表示と `]` プロンプトに到達することを確認する。
4. キーボードから `MAP` を入力し、VDG画面に構成情報が表示されることを確認する。
5. UARTを接続している場合は、UARTからも従来どおり入力できることを確認する。

## SDFS/68起動確認

1. ROMモニタの `]` プロンプトで、キーボードから `BOOT` を入力する。
2. VDG画面に `SDFS/68` のバナーと `SDFS>` プロンプトが表示されることを確認する。
3. `DIR` を入力し、`SDFS.BIN` などのroot directory内容が表示されることを確認する。
4. `DIR` 実行直後に、UART表示よりVDG表示だけが1行多く空く現象が出ないことを確認する。
5. `LOAD ファイル名` または `L ファイル名` でS-RecordまたはIntel HEXを読み込めることを確認する。
6. `RUN アドレス` または `RUN ファイル名` で実行できることを確認する。
7. `EXIT` でROMモニタの `]` プロンプトへ戻れることを確認する。

## VDG向け表示確認

1. ROMモニタへ戻った後、`DS0100` を入力する。
2. VDG画面で、1行が32桁以内に収まり、次のような8 byte/行表示になることを確認する。

```text
0100 00 01 02 03 04 05 06 07
```

3. 既存の `D0100` は従来の16 byte/行表示のままであることを確認する。

## 判定

#170 を閉じるには、少なくとも次を満たす必要がある。

- VDG画面上で `] BOOT` 後に `SDFS>` と `DIR` 結果が見える。
- キーボードからSDFS/68コマンドを入力できる。
- `DIR` / `LOAD` / `RUN` / `EXIT` がVDG+keyboard構成で操作できる。
- 1st ACIA UART未接続でも起動表示で停止しない。
- UART接続時はデバッグ用の逃げ道として使える。
