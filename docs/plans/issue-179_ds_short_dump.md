# Issue #179 DS短幅ダンプ

## 背景

既存の `D` コマンドは16 byte/行で、アドレス、HEX、ASCII欄を含めるとVDGの32桁画面では大きく折り返される。
一方、既存 `D` のUART向け表示は既存利用とテストの前提になっているため変更しない。

## 採用方針

- 新規コマンドは `DS` とする。意味は Dump Short。
- 対象は `FEATURE_VDG=1` のROMだけにする。
- `D` / `Dssss` / `Dssss-eeee` の既存仕様は変更しない。
- `DS` / `DSssss` / `DSssss-eeee` は既存 `D` と同じ引数規則を使う。
- `DS` は8 byte/行、ASCII欄なしにして、各行を32桁以内に収める。

## 表示形式

```text
0100 00 01 02 03 04 05 06 07
```

上記は28桁で、VDG 32桁画面内に収まる。

## 検証方針

- `DS0100` と `DS0100-011F` が8 byte/行で出ることを smoke test で確認する。
- `DS` の出力行が32桁以内であることを固定する。
- 不正な `DS` 引数が `?` になることを確認する。
- 既存 `D` のテストを維持する。

## 対象外

- 既存 `D` の表示幅変更。
- 非VDG profileへの `DS` 常駐。
- ASCII欄や罫線付きの拡張表示。
