# #201 VDG有効時のUART送信待ち切替

## 背景

#183 で `FEATURE_VDG=1` のROMは、1st ACIA の `TDRE` が立たない場合でもVDG出力を優先して進むようにした。
これにより、USBシリアル未接続や制御線状態に左右されず、VDG + keyboard のスタンドアロン環境で起動とSDFS/68操作を継続できる。

一方で、USBシリアルを接続してMac側でUARTログを見ている場合、6800側の表示処理が9600bpsの送信時間より速く進み、`TDRE` が立つ前の文字を捨てるためUART側に文字取りこぼしが出る。

## 採用方針

- VDG有効ROMでは、UART送信待ちをRAM上の1 byteフラグで切り替える。
- デフォルトはOFFとし、スタンドアロン性を優先する。
- `UW ON` で従来どおり `TDRE` が立つまで待つ。
- `UW OFF` で送信不可なら捨ててVDG出力を止めない。
- 有限待ちタイムアウトは採用しない。MC6800では文字ごとの短待ちでも体感遅延と調整余地が出るため、明示的なON/OFFの方が挙動を理解しやすい。

## コマンド仕様

- `UW`: 現在状態を `UW ON` または `UW OFF` と表示する。
- `UW ON`: UART送信待ちを有効にする。1st ACIA が送信不可なら停止し得る。
- `UW OFF`: UART送信待ちを無効にする。起動時のデフォルト。

`UW` は `FEATURE_VDG=1` のROMだけで有効にする。非VDG profileでは、従来どおりUART必須コンソールとして `ACIA_PUTC` が送信待ちする。

## 検証方針

- VDG buildで、`UW` の初期状態がOFFであることを確認する。
- `UW ON` / `UW OFF` の切替表示を smoke test に追加する。
- `--acia-tdre-stuck-low` では、デフォルトOFFの起動が止まらないことを既存テストで維持する。
- `UW ON` 後は `TDRE` stuck low でエミュレータのサイクル上限に達し、送信待ちに入ることを確認する。
